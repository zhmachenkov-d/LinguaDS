# Adversarial Review — English Path UX

**Scope:** `DESIGN.md`, `EXPERIENCE.md`, `.memlog.md`, `imports/*`, `mockups/*`  
**Lens:** anti-gamification + sparse Quiet Study integrity  
**Stance:** assume implementers will copy the densest, most “complete” artifact they see.

## Overall verdict

**Conditional fail on integrity.** Spines state the Quiet Study / anti-gamification locks clearly, but promoted mocks and lingering import language train the opposite habits: denser Level-transition table than UJ-1 first paint, Start that reads as a filled gate, slash-IPA on status surfaces, “overlay” naming, and no visual contract for interview debrief or Self-check-yes / Case A·C / Block-A-underway climaxes. Without mock + copy guards, build will reintroduce dashboard density, Start-as-event, and verdict chrome while claiming spine compliance.

## Findings (severity-tagged with Fix)

### Critical

1. **Denser Level transition than UJ-1 emptiness**  
   **Where:** `DESIGN.md` Path map (“fuller on first launch / Level transition”); `mockups/level-transition.html`; Brand & Style vs memlog “sparse forever, not denser on debrief/map”.  
   **Trigger:** Criteria table (4 columns × 4 rows) + transition title + Path map + Goes into review + next is a status dashboard; DESIGN itself invites “fuller” map density.  
   **Fix:** Delete “fuller” permission. Cap UJ-3 to the same emptiness budget as UJ-1 greeting (short factual stack, no table chrome unless every row is one hairline line). Rebuild `level-transition.html` to match greeting sparseness; keep Case B content but cut visual mass.  
   **If unfixed:** Debrief/map become the densest surfaces → Quiet Study collapses into assessment UI.

2. **Return open denser than locked “three lines”**  
   **Where:** `EXPERIENCE.md` UJ-2 / State Patterns; `mockups/return-open.html`; `mockups/direction-paper-lamp.html`.  
   **Trigger:** Mock shows last-stop meta + Unstable + Available (separate hero lines) + Next + Path + Start + plan — more than “three lines + compact map + field/mic + quiet Start”. Available is elevated to equal weight with Unstable.  
   **Fix:** Collapse Unstable·Available onto one line per UJ-2 lock; demote Path to mute single line; remove plan-from-open as always-on body copy or mark it as timed state only. Align mock pixel budget to UJ-1 greeting strip.  
   **If unfixed:** Return open becomes a mini Path dashboard every evening — gamification via information density.
