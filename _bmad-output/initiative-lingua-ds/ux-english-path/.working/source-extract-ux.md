# UX source extract — PRD + spec (Discovery aid)

Not a spine. Decisions still live in memlog after coaching.

## Product / audience

- Local/desktop DeepSeek Harness coach; v1 = builder + trusted circle (internal/pilot)
- Russian L1 adults; work-ready English; near-term B1+/interview; Goal C1 on map as horizon
- Retention: clear plan + transparency + soft advance — **not** streaks/badges/XP

## Form-factor (implied)

- Desktop Harness host UI (sparse shell); voice + text channels equal; mic optional without reproach

## Surfaces / flows UX must cover (from CAP / UJ)

| Surface / moment                                                                         | Bind                                                          |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| First-launch Session (greeting → prefs → diagnostic → Path map → first phonics → finale) | UJ-1 / CAP-1                                                  |
| Return open (neutral resume; Agent-named plan; no chooser)                               | UJ-2 / CAP-2                                                  |
| Orientation / transparency strip                                                         | level · Topic · Session goal · Available/Recommended/review   |
| Recommended review block + Self-check (side-by-side audio, no praise)                    | UJ-2, UJ-5                                                    |
| Level transition overlay (evidence, not victory)                                         | UJ-3 / CAP-3                                                  |
| Phonics lesson micro-structure                                                           | UJ-5 / CAP-4                                                  |
| Interview practice (~45–60 min genre)                                                    | UJ-4 / CAP-6                                                  |
| Session finale descriptors                                                               | Confirmed / Unstable / Goes into review / next                |
| Path map object                                                                          | A0→C1, you-are-here, Goal C1 horizon, B1+/interview near-term |

## Hard UI bans (Learner-facing)

unlocked · level up · reward · streak · XP · badge · points · % as progress framing · welcome-back / missed-days guilt · mode/topic/continue-vs-review chooser · aloud “wrong” on STT · praise theater on Self-check · victory animation on Level advance

## Glossary status terms (exclusive)

Confirmed · Almost confirmed · Unstable · Goes into review · Available/Open · Recommended (map) · Threshold reached · Conditionally available · Not available/Not open · Critical criteria · Within-level queue · Readiness list rows (interview)

## First-paint notes (PRD addendum)

- Sparse: short line, input, mic — no cards/progress bars/illustrations at first paint
- ≤3 setup prefs only; defaults mixed / whatever / 10 min

## Concern scan candidates

accessibility (voice+text), bilingual RU/EN/mixed instructions, desktop, anti-gamification brand, motion (restraint?), offline/local, content density (sparse), input modalities (mic/text), i18n instructions vs practice language
