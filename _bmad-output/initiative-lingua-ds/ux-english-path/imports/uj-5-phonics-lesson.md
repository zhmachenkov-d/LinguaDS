# UJ-5 — A0 Phonics Lesson as a Step Named by the Agent

User-authored Discovery import. Spines win on conflict after Finalize reconcile.

Form-factor: local desktop Harness shell. Same lesson shape that closes UJ-1; here as a named Agent step. No gamification. No IPA-first UI. No spelling as goal. Self-check is the core.

## Feel

Laboratory of one sound: slow and narrow (one contrast); bodily articulation (mouth diagrams, not rules); no writing (picture + sound); Self-check = Learner judges; Within-level queue (unstable sound does not make next lesson Not available).

## Open state

Agent names step in one sentence; plan blocks with timings; lesson underway — no Start-lesson menu. Plan/fixation may use slash IPA to name the contrast; drill canvases do not.

## Blocks

1. **Ear (~2):** almost empty; same/different after first listen; slow/exaggerate if needed; no right/wrong aloud.
2. **Articulation (~2):** static mouth-profile diagrams (no IPA labels); one record; two unlabeled tracks (own + reference); one concrete physical correction at a time.
3. **Words (~2):** pictures + play; auto-record on repeat; no spelling; sparse physical cue only.
4. **Mini-contrast (~1):** hear→picture, picture→produce; neutral next; no score counts.
5. **Self-check (~2):** two play buttons + “Do you hear the difference?” yes/no; agent waits for Alex; no praise; if no → slowed replay + point; may record “does not distinguish own recording.”
6. **Fixation (~1):** Confirmed/Unstable/Goes into review / Within-level queue / next lesson — facts only; next lesson stays Available.

## Never

IPA-first UI · spelling · praise/wrong · scores/% · progress bars · XP/badge · unlock language · vague “try again” · almost-there · alarm colors · Continue? gates · Start-lesson · peer compare · lecture why · auto-grade without Self-check · hide queue · block next lesson for within-level unstable · countdown · animated tongue spectacle · mascot · Skip block.

Near misses: labeled “reference,” green check on yes, Good!, animated diagram, block 1/6 meter, “weak sound” wording, auto-compare without question, skip Self-check when agent “sure.”
