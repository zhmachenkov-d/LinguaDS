# UJ-1: First Launch — What Happens for Alex

User-authored complete first-launch walkthrough (Discovery import). Spines win on conflict after Finalize reconcile.

Without gamification: no points, badges, streaks, or “level up” animations. Only screen, voice, text, and statuses.

## Beat 0. Installation (before the first screen)

Alex installs the DeepSeek Harness desktop app, adds the `english-path` profile, and puts `DEEPSEEK_API_KEY` into the environment. The app sees an empty profile — meaning this is the first launch, and onboarding turns on.

This is not a separate “setup wizard” of ten steps. It is one session that begins with a greeting and ends with the first lesson.

## Beat 1. Greeting (what he sees and hears)

The screen is almost empty. No cards, progress bars, or illustrations. At the top — a short line, below — an input field and a microphone button.

Alex **hears** a voice and **sees** text at the same time (bilingual EN sample + L1 instructions). Key: instructions in L1, English as a sample, not a requirement. Voice preferred; mic not mandatory; text field without reproach. Explicit “stop at any time.”

## Beat 2. Setup before diagnostics (≤3 questions)

1. Language of instructions: Russian / English / mixed (default mixed).
2. Format: voice / text / whatever works (default whatever).
3. Session length: 10 / 20 / 30 (default 10).

No interests, career goals, or topic prefs. Goal: C1 shown in one line — path is long; start from the beginning.

## Beat 3. Diagnostic conversation (adaptive, not a test)

Probe order: name → origin/home → alphabet → letter reading (3–4 letters on screen) → contrast sounds (/θ/ /s/) → one production word (_think_).

Rules: no prompting answers; RU hints OK; no aloud right/wrong; early-stop; silence 5–7s → slower repeat → RU → move on. Duration 5–8 min.

~8 min phonics A0.0: ear → articulation → words → mini-contrast → fixation. Alphabet in 5–6 letter audio-first batches.
