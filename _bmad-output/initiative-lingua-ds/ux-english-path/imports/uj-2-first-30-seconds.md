# UJ-2 First 30 Seconds — Design Brief

User-authored Discovery import. Spines win on conflict after Finalize reconcile.

Form-factor: local desktop Harness shell. Return is continuation, not an event. **No greeting in the first 30 seconds.** First spoken phrase is the plan, not “welcome back.”

## Feel

1. Immediate — frame renders complete.
2. Continuation, not a start.
3. No pause for a decision — agent names the plan.
4. You can do nothing — first block is listening; no press required to begin.
5. No counting — no days, streaks, “day 2.”

## Open state (three lines + channel)

- Top left, small, low contrast: last session length + stop point.
- Regular: Unstable · Available.
- Secondary: Next step.
- Lower third: input focused (no label/placeholder) + mic + **quiet Start** (B2). Start does **not** block hearing the plan or beginning auditory Block A; it is not a mode/topic/continue-vs-review chooser.
- Compact Path map A0→C1 with you-are-here **is shown** on return (B1) — status vocabulary only, **never** a fill gauge / thin progress bar. Goal C1 horizon + B1+/interview near-term milestone remain visible.

## Timeline 0–30s

| Time   | Sees                       | Hears                                        |
| ------ | -------------------------- | -------------------------------------------- |
| 0–2s   | Three lines, field focused | Silence                                      |
| 2–6s   | Plan as text               | Agent names plan (unstable → new → length)   |
| 6–15s  | Unchanged                  | Silence; waits                               |
| 15–25s | Unchanged                  | Same plan once, slower — no “are you there?” |
| 25–30s | Block A: auditory only     | First minimal pair                           |

At ~25s the lesson is **already underway** without a press. Block A = auditory discrimination.

## Agent-named plan (always same order)

1. What remained unstable (return, not a check).
2. What is introduced as new (one element).
3. How long (one number, no range).

Neutral wording: “what remained unstable,” not “check if you remember.” Alex may interrupt; he cannot fail to hear the plan.

## Review as first block

Not a screen, mode, or heading. Same visual language as other blocks. No “review mode” chrome. List lives in open-state one-liners only. Shortens if discrimination holds; expands to full ear-tuning if not.

## Never appear (summary)

Welcome-back · streak/day counts · missed-days · progress bar/% · badge/XP · Start-as-chooser / loud gate · mode/topic/length chooser · continue-or-start-over · Review heading · motivational fluff · trend arrows on open · alarm colors · zero dashboards · mascot · “Let’s go!” · non-agent startup sound · previous-session modal. Quiet Start (B2) allowed.

Near misses also banned: named welcome, “Ready?”, pulsing mic coachmark, thin A0→C1 fill gauge, language toggle inviting a decision, soft highlight marking Block A as review.
