# UJ-4 — Interview Practice, B1+, as a Scenario

User-authored Discovery import. Spines win on conflict after Finalize reconcile.

Form-factor: local desktop Harness shell. Scenario session: plan → prep → mock → debrief (± second pass). Formal/neutral register in mock. No mid-answer prompting. Finale: descriptors + readiness rows — no pass/fail, score table, or badge.

## Feel

Rehearsal in a real room: whole plan named before start; meta-voice (prep/debrief) vs interviewer voice (mock); no help during take (announced before); debrief is a map not a grade; 45–60 min default, changeable **in advance** only.

## Open state (differs from UJ-2)

- Names longer plan + blocks, not only next step.
- One confirmation: time ([45] [60] [other]).
- First block = prep, not review.
- States: formal/neutral register; no hints during answers; stop anytime.

## Block 1 — Prep (~12 min)

Working surface, not a wizard: posting (left) · keywords plain text (right) · raw material field (“facts, not answers”) · functional language strip · one STAR structure on his own case. Agent speaks sparingly (start + ~8 min STAR nudge).

## Block 2 — Mock (~20 min)

Screen nearly empty: dimmed keywords · “take in progress” + elapsed · **Stop only**. No transcript, live feedback, block progress, pause, hint. Interviewer in character: small talk → about yourself → experience → skills → scenario → his questions. Polite interrupt + 1–2 unexpected Qs. Once: “Starting. I am the interviewer.”

## Block 3 — Debrief (~15 min)

Descriptor summary (no score numbers as hero) + Readiness list six rows. Fragment review of 2–3 moments without praise. Patterns into review (condition under pressure), not single-error shame.

## Block 4 — Second pass (optional, after debrief)

Offered not imposed. Same screen/interviewer pressure. Comparison arrows across two runs only — never % or +points.

## Finale vs ordinary session

No single Confirmed/Unstable finale shape; six readiness rows; “not checked” valid; pattern-level weak reasons; agent does not certify “ready to apply.”

## Never

Mid-answer help · praise in mock · live error transcript · pause · block progress meter · score/%/grade/CEFR-as-result · pass/fail · badge · countdown timer · score table · first-debrief trend arrows · almost-ready encouragement · row color coding · apply-for-jobs next step · interviewer breaking character · avatar/face · “simulation complete” · hiding not-checked · 4-of-6 ready percentage.
