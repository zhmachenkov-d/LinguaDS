# UJ-3 — Level Transition Overlay at the End of a Session

User-authored Discovery import. Spines win on conflict after Finalize reconcile.

Form-factor: local desktop Harness shell. Not a modal/pop-up with shadow and dimming — the **final canvas state** when the agent evaluates a Level transition. Only when enough evidence exists; otherwise usual session finale (UJ-1/UJ-2). End-of-session only; not a separate event screen.

## Feel

Calm review, not reward or verdict: static complete frame; factual (criteria, evidence, status); same voice tone as the lesson; reversible current assessment; next step at bottom — closes session, not trajectory.

## Render shape

Text + criteria table + statuses only. No icons, colors, bars, checkmarks. Compact Path map with you-are-here. Next session line always present.

Criterion rows show: name · threshold · evidence · status. Evidence prefers counts (20 of 26), not a percentage as the hero number.

Illustrative criterion rows in examples are **not** locked Critical matrices (assessment calibration owns lists/thresholds).

## Status vocabulary (locked — glossary-aligned, option A)

**Transition:** Available · Conditionally available · Not available / Not open

**Criterion:** Confirmed · Almost confirmed · Unstable · not confirmed (critical unmet — blocks)

**Dual Path status:** transition status + Goes into review list (items remain in work regardless of transition outcome).

Learner-facing copy uses glossary terms exactly. Do not say Unavailable, unlocked, or conditional as a status word. Path map keeps Goal C1 horizon + B1+/interview near-term milestone.

## Cases

- **A Available:** all confirmed; next = next-level materials; voice factual — no congratulations.
- **B Conditionally available:** critical confirmed; non-critical Unstable/Almost confirmed; A1 open with review weave; no “almost there.”
- **C Not available:** critical not confirmed; reason named; other confirmed criteria stay shown and do not burn; no “unfortunately” / failure framing.

## Never

Victory animation/confetti · congratulations · unlock/level-up language · fill-to-100% bar · badge/XP · burned progress · alarm colors · almost-there motivation · % as main number · words-left counter · modal Close gate · dimming/shadow pop-up · emoji/icons · peer comparison · quotes · path-map animation · staggered checkmarks · victory/win/success words · tonal shift by case.

Near misses: checkmarks, green-for-available, “Good!”, soft “yet,” dramatized critical highlight, Start-A1 button in Case B, hiding confirmed rows in Case C, dismiss animation.
