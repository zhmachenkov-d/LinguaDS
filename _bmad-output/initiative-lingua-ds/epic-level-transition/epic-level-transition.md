# Soft level transition

## Description

Delivers CAP-3: Session finale can show Level-transition evidence and dual Path-map access status (Available / Conditionally available / Not available) with soft/conditional advance; A0→A1 Critical hard-block only from `pilot-calibration.md`.

## Outcome

When Level criteria are assessed, the Learner sees honest access status and pending review — no rewards, no burned-progress spectacle, no invented Critical lists beyond the pilot A0→A1 gates.

## Done when

1. Soft advance allows next-level materials with named Goes-into-review items; no level rollback spectacle.
2. Unmet Critical criteria for A0→A1 keep next level Not available; Within-level queue items never block the next lesson.
3. Overlay is end-of-Session, not a standalone open flow; assess returns GateEval; supervisor commits `level_advance` only from that contract.
4. Behavior ships in the installable `english-path` bundle with Path map family consistent with first-launch/return.

## Boundaries

CAP-3 only. Critical matrices for other Level transitions stay principle-only (non-goal). Not: full path coach curriculum, interview readiness rows, phonics Within-level rules (owned by phonics).
