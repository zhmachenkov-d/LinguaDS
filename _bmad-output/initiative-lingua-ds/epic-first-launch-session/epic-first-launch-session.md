# First-launch Session

## Description

Delivers CAP-1: an empty-profile Learner completes one continuous first Session (UJ-1 tracer) — bilingual greeting, ≤3 setup prefs, Diagnostic conversation (stub OK where adaptive detail waits), Path map, same-Session thin first Phonics block, descriptor finale — on real local persistence.

## Outcome

An empty-profile Learner finishes first launch having oriented, been placed without test anxiety, seen the path, and completed a real learning act — the initiative tracer demo.

## Done when

1. Empty profile triggers first-launch continuous Session (not a multi-step wizard) inside the installable `english-path` bundle.
2. Session includes greeting, ≤3 prefs, Diagnostic path, Path map, thin first Phonics learning act, and descriptor finale without ending on a hollow “done” onboarding screen.
3. Prefs and path/plan/evidence shapes persist via journal/projection for return; status language never uses unlocked/points/%.
4. Supervisor alone names the plan and commits durable mutations; thin phonics uses channel handoff without inventing a parallel free-text availability model.

## Boundaries

CAP-1 only. Thin first Phonics is a learning-act MVP; full A0 phonics + CAP-8 voice bar deepen in epic-a0-phonics-voice. Not: return shell, level overlay, interview, full coach set.
