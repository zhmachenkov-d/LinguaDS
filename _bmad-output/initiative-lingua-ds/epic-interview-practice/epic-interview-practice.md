# Interview practice

## Description

Delivers CAP-6: at/near B1+/interview milestone, Interview practice via Agent-named plan (prep → mock → debrief → optional second run) with descriptors and Readiness list — not binary pass/fail.

## Outcome

A Learner at/near the B1+/interview milestone runs Interview practice and leaves with descriptors plus a Readiness list under soft entry rules.

## Done when

1. Named only under soft entry in `pilot-calibration.md` (path at/near B1+ or assess proposes); no mode-picker entry.
2. Prep → mock → debrief (+ optional second run) holds formal/neutral mock register with pause/interrupt + 1–2 unexpected questions; length override ~45–60 min stated up front.
3. Readiness rows use interview-only RU statuses with enough-runs heuristics; never hide не проверялось; no binary pass/fail.
4. Ships in the installable `english-path` bundle; speaking coach handoff per AD-3; assess owns ReadinessRow semantics (AD-10).

## Boundaries

CAP-6 interview genre only. Soft entry depends on path/assess from prior epics. Not: general speaking syllabus (CAP-5), Critical Level matrices beyond pilot, certification product.
